AI 干净复制 隐私权政策

生效日期：2026 年 10 月 27 日　版本：v1.4.1　产品：AI 干净复制 Chrome 扩展程序

本政策与产品内的说明一起，完整披露本扩展如何收集、使用和共享用户数据，以及会与哪些方共享数据。

1. 本扩展是干什么的

单一用途：把用户在网页上选中或指定的 AI 回答、文章正文，在本地清理格式后复制到剪贴板，或下载为本地 .md 文件，解决直接复制到 Word、微信、笔记软件时列表、代码块、表格错乱的问题。

2. 收集哪些用户数据、怎么收集

数据类型是否收集怎么收集
网站内容：用户指定复制的网页文字（AI 回答、文章正文）是，仅在本地处理用户点击复制按钮、选中内容浮动条、右键菜单或弹窗按钮后，内容脚本读取当前页用户指定的那段文字的 DOM。没有点击复制，就不会把这段文字用于复制；扩展不在后台持续抓取页面内容。
用户设置：默认复制格式、是否去掉引用角标、表格是否转 Markdown、代码块是否保留语言标记是，仅存本地用户在弹窗里自己改动后，保存在浏览器本地存储。
个人身份信息、健康信息、财务和付款信息、身份验证信息、个人通讯、位置、网络记录、用户活动否本扩展不建立账号，不读取密码、通讯、位置、浏览历史，不做点击、滚动等行为跟踪，不做统计分析。

3. 数据怎么使用

  • 网站内容只用于一件事：在用户浏览器本地把格式清理干净，生成 Markdown、纯文本、富文本或 Word 文本，再写入剪贴板或下载为本地文件。
  • 用户设置只用于记住用户上次的选择，下次打开弹窗不用重设。
  • 数据不用于广告、不用于个性化推荐、不用于训练模型、不用于统计分析。

4. 数据与哪些方共享

不与任何一方共享。

  • 第三方服务商：无
  • 广告商：无
  • 分析服务：无，本扩展不接入 Google Analytics 或其他统计服务
  • 云服务器：无，数据不上传到任何服务器
  • 其他用户、其他应用：无

唯一的数据去向是用户自己的设备：剪贴板（用户主动复制时）和用户自己下载的本地文件。用户把复制结果粘到哪里，是用户自己的操作，不属于本扩展的共享行为。

5. 数据保存多久

网站内容不做云端保存、不做本地长期保存，转换完成后只存在于剪贴板或下载文件中，由用户自行控制。用户设置一直保存在浏览器本地存储，直到用户卸载扩展或清除浏览器数据。

6. 权限与数据对应关系

  • clipboardWrite：用户点击复制后，把本地转好的结果写入剪贴板；
  • storage：保存上述 4 项用户设置；
  • contextMenus：提供选中文字的右键复制菜单；
  • activeTab：用户点击弹窗或菜单时，向当前标签页发送复制指令；
  • 主机权限：让内容脚本能在用户打开的 AI 对话页和文章页上识别正文并显示复制按钮。

7. 政策变更

如本政策变更，会在商品详情页更新本政策。本扩展如未来改变数据处理方式，会先更新本政策再发布新版本。

8. 联系方式

如对本政策有疑问，请通过 Chrome 应用商店商品页提供的开发者联系方式联系开发者。

Privacy Policy

Effective date: 27 October 2026　Version: v1.4.1　Product: AI Clean Copy Chrome Extension

This policy, together with the disclosures in the product, fully discloses how this product collects, uses and shares user data, and all parties user data will be shared with.

1. What this product does

Single purpose: to clean up the formatting of AI answers or article text that the user selects or specifies on a web page, locally in the browser, and copy it to the clipboard or download it as a local .md file, so that pasting into Word, WeChat or note apps does not break lists, code blocks or tables.

2. What user data is collected, and how

  • Website content — the text the user asks to copy: collected only for local processing. After the user clicks a copy button, the selection bar, a context-menu item or a popup button, the content script reads the DOM of that specified text on the current page. It does not continuously scrape pages in the background.
  • User settings — default copy format, remove citations, table as Markdown, keep code language: stored only in the browser's local storage, after the user changes them in the popup.
  • Personal identity, health, financial, authentication, personal communications, location, web history and user activity data: not collected. The product has no accounts, does not read passwords, messages, location or browsing history, and does no tracking or analytics.

3. How user data is used

Website content is used only to clean up its formatting locally and produce Markdown, plain text, rich text or Word text for the clipboard or a local download. Settings are used only to remember the user's choices. Data is not used for advertising, personalisation, model training or analytics.

4. All parties user data is shared with

None. No third-party service providers, advertisers, analytics services or cloud servers receive user data. Data is not uploaded to any server. The only destinations are the user's own device: the clipboard, when the user clicks copy, and a file the user downloads. Where the user then pastes the result is the user's own action, not sharing by this product.

5. Retention

Website content is not stored on a server and is not kept long-term locally; after conversion it exists only in the clipboard or the downloaded file, under the user's control. Settings remain in local browser storage until the extension is uninstalled or browser data is cleared.

6. Changes and contact

If this policy changes, it will be updated on the product listing page, before any change in data handling takes effect in a new version. Questions can be sent through the developer contact information on the Chrome Web Store listing page.
